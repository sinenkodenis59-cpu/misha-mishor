# Вилла Мисхор

Лендинг для частного семейного дома у моря — Ялта, пгт. Алупка (рядом с
Юсуповским дворцом). Одностраничный сайт со сценарной анимацией: 3D-фон
на герое (Three.js), плавный скролл (Lenis), покадровые ревилы и
горизонтальная «pinned»-галерея на GSAP/ScrollTrigger.

Сайт не требует сборки — это чистые HTML/CSS/JS, все библиотеки уже
самостоятельно упакованы в `assets/vendor/` и `assets/fonts/` (без
обращения к внешним CDN, кроме карты и самого 3D-тура).

## Как открыть локально

```bash
python3 -m http.server 8080
# затем http://localhost:8080/index.html
```

Или любым другим статическим сервером (`npx serve`, `php -S` и т.д.) —
open `index.html` напрямую через `file://` тоже работает, кроме
`import maps` для Three.js в некоторых браузерах.

Фото пересняты из видео на полном 1920×1080 (не 1600px) с лёгкой
доводкой резкости — это разрешение самого источника (видео 1080p), выше
без ИИ-апскейла (недоступен из этой сети) не поднять.

**Про видео:** из исходного ролика вырезаны два фрагмента с наложенным
текстом — «ДОМ 200 м²» и «350 М до пляжа» — потому что они расходятся с
проверенными фактами (240 м² в задаче) и неподтверждённым расстоянием до
пляжа. Остальное — как было, включая кадры реальной стройки в начале.

Если понадобится заменить какое-то фото или видео — просто перезапишите
файл с тем же именем, в коде ничего менять не нужно.

## Чертежи (планировка и генплан)

`assets/images/plan-*.png` — настоящие чертежи проекта М1:100, присланные
как PDF («План подвала / первого / второго / мансардного этажа»),
разрезанные на 4 файла и обрезанные под каждый этаж (`assets/images/plan-basement.png`,
`plan-floor1.png`, `plan-floor2.png`, `plan-mansard.png`). В разделе
«Планировка и генплан» (`index.html`, `#floors`) они показаны в
переключателе «Чертёж / Фото» с лайтбоксом по клику (полноэкранный
просмотр). Отдельного генплана участка (с границами и посадкой дома) в
присланных файлах не было — вместо выдумывания подставлен честный блок
«Участок» с аэрофото и пометкой «генплан — по запросу у застройщика».

Названия этажей в тексте сайта («Подвал», «Первый этаж», «Второй этаж»,
«Мансарда») взяты дословно с чертежей — раньше в макете были придуманные
названия («Нижний/Средний/Верхний этаж», «Кровля»), сейчас везде (в
блоке «О доме» и в «Планировке») используется одна и та же, реальная
терминология проекта.

## Что ещё нужно заменить перед публикацией

- **Контакты** в разделе «Контакты» (`index.html`, `#contact`) — сейчас
  телефон и e-mail — заглушки (`+7 (000) 000-00-00`,
  `hello@villa-mishor.ru`).
- **Форма заявки** — визуально готова, но не подключена к серверу/CRM
  (`assets/js/main.js`, `initForm()` просто показывает «Заявка
  отправлена»). Нужно привязать к реальному приёму заявок (email-сервис,
  Telegram-бот, CRM-вебхук и т.п.).
- Адрес в тексте указан как дан в задаче — «Ялта, пгт. Алупка» — при этом
  ссылка на 3D-тур называется `viila-miskhor` (Мисхор). Это соседние
  посёлки Южного берега Крыма; при публикации стоит сверить точный посёлок
  с документами на дом.

## Структура

```
index.html               разметка и весь текстовый контент
assets/css/style.css      дизайн-система, вёрстка, анимационные состояния
assets/css/fonts.css      self-hosted @font-face (Playfair Display, Manrope — кириллица+латиница)
assets/js/main.js         Lenis, ScrollTrigger-ревилы, курсор, бургер-меню, счётчики, pinned-галерея,
                          переключатель чертёж/фото и лайтбокс для планировки
assets/js/three-scene.js  3D-фон героя (низкополигональный хребет + частицы)
assets/vendor/            запакованные gsap / ScrollTrigger / lenis / three (без внешних CDN)
assets/fonts/             woff2-файлы шрифтов
assets/images/            фото дома (photo-*.jpg) и чертежи (plan-*.png), см. таблицы выше
assets/video/             смонтированный видео-ролик (villa-mishor-tour.mp4)
```
